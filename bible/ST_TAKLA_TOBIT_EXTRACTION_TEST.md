# اختبار الوصول إلى النص اليسوعي من St-Takla — سفر طوبيا

التاريخ: 2026-11-28

## نتيجة فحص الموقع

- يعرض الموقع سفر طوبيا تحت رقم الكتاب 17.
- صفحة السفر تعرض 14 إصحاحًا.
- الصفحة تعلن صراحة: «الترجمة اليسوعية القديمة 1877 م».
- صفحة الإصحاح 2 تعرض الآيات مرقمة داخل HTML، ويمكن فتح كل آية برابط مستقل.
- فحص صفحة الإصحاح 2 يدويًا أظهر الآيات 1 إلى 22 دون فجوات.
- لذلك لا نحتاج إلى OCR للنسخة المعروضة في الموقع. النص موجود كنص HTML قابل للاستخراج.

مصادر الفحص:
- https://st-takla.org/Bibles/BibleSearch/showChapter.php?book=17&chapter=2
- https://st-takla.org/Bibles/BibleSearch/showVerses.php?book=17&chapter=2&vmax=4&vmin=3
- https://st-takla.org/Bibles/BibleSearch/showVerses.php?book=17&chapter=1&vmax=2&vmin=1

## أداة الاستخراج التجريبية

الملف:
`bible/tools/extract_st_takla_tobit.py`

التشغيل:
```bash
python -m pip install beautifulsoup4
python bible/tools/extract_st_takla_tobit.py --chapter 2 --output /tmp/tobit-chapter-2.jsonl
python bible/tools/extract_st_takla_tobit.py --output /tmp/tobit-research-candidate.jsonl
```

الأداة:
- تقرأ صفحات الإصحاحات مباشرة.
- تستخرج رقم الآية والنص من روابط الآيات.
- تتحقق من تسلسل الأعداد وعدم وجود فجوات.
- ترفض الصفحة إذا تغير هيكل HTML ولم تستطع استخراج الآيات.
- تضع علامة UNVERIFIED_RESEARCH_CANDIDATE على كل سجل.
- تحفظ النتائج محليًا ولا تعدل ملفات التطبيق أو corpus.

## حدود النتيجة الحالية

تم التحقق من بنية صفحات الموقع وقراءة إصحاح 2 في العرض المنشور. لم يتم تشغيل أداة Python من بيئة GitHub Actions بعد، لذلك لا ندعي أن الاستخراج الآلي الكامل قد اجتاز الاختبار.

كذلك، وصف الموقع للترجمة لا يثبت وحده أن كل نص الصفحة مطابق حرفيًا لنسخة مطبوعة بعينها، ولا يمنحنا تلقائيًا حق إعادة نشر النص المستخرج داخل التطبيق.

## القرار

هذا المسار أسرع من تنزيل صور الطبعة وتشغيل OCR، وهو المرشح الأول للحصول على نسخة عمل ومقابلتها.

لا يتم نقل أي سجل من ملف research candidate إلى corpus التطبيق قبل:
1. تشغيل الأداة ومراجعة نتائجها.
2. مقارنة عينات من كل سفر مع شاهد مطبوع أو مصدر تاريخي مستقل.
3. مطابقة قائمة الأسفار والإصحاحات والأعداد مع القانون القبطي الأرثوذكسي.
4. حسم الإذن القانوني لإعادة نشر النص المستخرج.
