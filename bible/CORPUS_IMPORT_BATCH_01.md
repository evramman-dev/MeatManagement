# خطة استيراد الدفعة الأولى من النصوص الكتابية

تاريخ المراجعة: 2026-11-25

## الهدف

تجهيز أول مجموعة نصوص قابلة للتنزيل والفحص، مع إبقاء كل طبعة مستقلة. هذه الخطة لا تعني أن الملفات نُزّلت أو أن النصوص أصبحت جزءًا من التطبيق.

## مصادر تم التحقق من صفحاتها

| الطبعة | صفحة المصدر | الصيغة المناسبة | وضع الحقوق والتغطية |
|---|---|---|---|
| WLC العبرية | https://ebible.org/find/details.php?id=hboWLC | USFM / USFX | النص Public Domain. بيانات OSHB الصرفية لها ترخيص مستقل. |
| السبعينية Rahlfs 1935 | https://openscriptorium.org/works | CSV أو API أو SQLite | مصنفة Public Domain في فهرس الأعمال. يجب تثبيت نسخة المصدر وتدقيق قائمة الأسفار. |
| اليونانية SBLGNT | https://github.com/LogosBible/SBLGNT | ملفات نصية من المصدر | CC BY 4.0 مع شروط SBL الإضافية. |
| اليونانية البطريركية 1904 | https://openscriptorium.org/works | CSV أو API | Public Domain وفق فهرس الأعمال. |
| القبطية الصعيدية للعهد الجديد | https://ebible.org/find/details.php?id=copcnt | USFM / USFX | الصفحة تعلن Public Domain، لكن مصدر النص منقول عن موارد منتدى ويحتاج مراجعة علمية. |
| القبطية البحيرية للعهد الجديد | https://ebible.org/find/details.php?id=copbhc | USFM / USFX | الصفحة تعلن Public Domain. طبعة Horner مع توحيد J. Warren Wells، والعمل موصوف بأنه مستمر. |

## تنزيلات Open Scriptorium

صفحة التنزيل الرسمية:
https://openscriptorium.org/downloads

تعرض CSV مستقلة:
- `wlc.csv` — 5.56 MB
- `rahlfs-lxx.csv` — 7.52 MB
- `patriarchal-1904.csv` — 1.74 MB
- `webbe.csv` — 4.54 MB

كما توفر قاعدة SQLite كاملة وواجهة API. كل عمل له ترخيص مستقل. يجب حفظ بيانات العمل والترخيص مع كل ملف وعدم اعتبار ترخيص التطبيق أو API ترخيصًا موحدًا لكل النصوص.

## شروط قبول أي ملف مستورد

1. حفظ رابط التنزيل الأصلي وتاريخ التنزيل واسم الطبعة والإصدار.
2. حفظ SHA-256 للملف الأصلي قبل فك الضغط.
3. حفظ إشعار الترخيص والنسبة داخل مجلد الطبعة.
4. استخراج عدد الأسفار والإصحاحات والأعداد لكل سفر.
5. كشف الأعداد المكررة أو المفقودة أو غير المتتابعة.
6. مقارنة عينات من بداية ووسط ونهاية كل سفر مع صفحة المصدر.
7. حفظ ترقيم المصدر كما هو، وعدم إجباره على ترقيم القانون القبطي.
8. عدم وضع نص في واجهة القراءة قبل اجتياز الفحص.

## قيود خاصة

- SBLGNT: لا تعرض اليونانية والإنجليزية في صفحة ثنائية متقابلة قبل حسم شرط ترخيص SBL الخاص بالـ diglot. يمكن أن تكون لكل لغة شاشة مستقلة.
- القبطية الصعيدية COPCNT: لا توصف بأنها طبعة مخطوطية نقدية؛ صفحة المصدر تشير إلى مصدر تفريغ غير أكاديمي واضح.
- القبطية البحيرية COPBHC: يجب حفظ اسم محرر التوحيد وملاحظة أن العمل مستمر.
- العهد القديم القبطي: لم نعثر في هذه الجولة على corpus كامل موثق ومتاح لإعادة التوزيع. يظل مشروع CoptOT الأكاديمي مرجع بحث لا ملفًا كاملًا جاهزًا.
- الإنجليزية WEBBE: لا نفترض أن محتواها يطابق القانون القبطي تمامًا قبل مقارنة الأسفار والتتمات.
- العربية: لم تُحل بعد حقوق التفريغ الرقمي للأسفار القانونية الثانية. لا نخلط فان دايك مع اليسوعية تحت اسم ترجمة واحدة.

## حالة التنفيذ

- تم التحقق من صفحات المصدر وروابط الصيغ المتاحة.
- لم يتم تنزيل الأرشيفات الثنائية إلى بيئة التنفيذ.
- لم يتم إدخال نصوص كتابية إلى المستودع.
- لم يتم تعديل واجهة التطبيق أو Service Worker أو Supabase.
- الخطوة التقنية التالية هي الحصول على ملفات المصدر الثنائية، ثم تشغيل تدقيق آلي لعدد الكتب والإصحاحات والأعداد قبل بناء ملفات التطبيق.
