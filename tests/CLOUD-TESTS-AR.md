# دليل اختبار MeatManagement من المتصفح

## 1. تجهيز بيانات الدخول

افتح مستودع MeatManagement على GitHub.

اذهب إلى:

Settings
ثم Secrets and variables
ثم Actions

اضغط New repository secret.

أضف السر الأول:

Name:
TEST_USERNAME

Secret:
اسم مستخدم حساب المختبر Chatgpt

ثم اضغط Add secret.

أضف السر الثاني:

Name:
TEST_PASSWORD

Secret:
كلمة مرور حساب المختبر التي وضعتها بنفسك.

لا تشارك كلمة المرور في المحادثات أو الصور.

## 2. تشغيل الاختبار

افتح تبويب Actions في المستودع.

اختر:

MeatManagement cloud browser tests

اضغط Run workflow.

ثم اضغط Run workflow مرة أخرى لتأكيد التشغيل.

## 3. متابعة النتيجة

انتظر انتهاء الاختبار.

افتح تشغيل الاختبار الذي انتهى.

ابحث عن قسم Artifacts.

نزّل الملف:

meatmanagement-browser-test-results

افتح الصور والتقارير الناتجة عن الاختبار.

## 4. إرسال النتائج للمراجعة

أرسل صور النتائج أو ملف التقرير للمراجعة.

الاختبار الحالي يراجع عرض الشاشات والتنقل بينها.

لا ينفذ عمليات بيع أو شراء أو إنتاج أو تحويل مخزني.

## 5. حماية الحساب

استخدم حساب SYSTEM_TESTER فقط.

لا تضع كلمة المرور داخل ملفات المشروع.

لا تستخدم حساب مدير النظام في الاختبارات الآلية.
