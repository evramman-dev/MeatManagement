استعادة ضبط المصنع

عملية واحدة تنظف بيانات التشغيل وتعيد البرنامج إلى وضع تشغيل نظيف. لا تحذف بيانات النظام أو البيانات الأساسية الحالية. أي تصنيف أو صنف أو وصفة أو عميل أو مورد أو مخزن أو خزنة أو قائمة أسعار أو أصل أو شريك أو أي بيانات أساسية تضيفها مستقبلًا تظل موجودة بعد ضبط المصنع. الحذف أو الإيقاف أو التعديل على هذه البيانات يتم يدويًا من شاشات الإدارة.

البيانات التي ستظل موجودة
كل البيانات المصنفة كبيانات نظام أو بيانات أساسية. تشمل الأدوار والصلاحيات والحسابات وإعدادات الشركة والمرجع الجغرافي والوحدات، وتشمل أيضًا الأصناف وتصنيفاتها وتحويلاتها وخيارات التعبئة والوصفات ومكوناتها والعملاء والموردين والمندوبين والمخازن والخزائن والشركاء والأصول وقوائم الأسعار وباقي السجلات الأساسية الحالية. أي إضافة مستقبلية إلى هذه البيانات تبقى بعد ضبط المصنع.
البيانات التي سيتم مسحها
بيانات التشغيل فقط مثل الفواتير والمرتجعات والتحصيلات والمدفوعات والمصروفات والقيود والحركات وأرصدة وتشغيلات المخزون وأوامر الإنتاج والرحلات والإشعارات وجلسات الجرد وسجل التتبع. لا تمس هذه العملية البيانات الأساسية أو إعدادات النظام.
تقرير ضبط المصنع
جهز التقرير أولًا. راجع أعداد البيانات التي ستمسح والبيانات التي ستظل. بعد اعتماد التقرير يظهر زر التنفيذ.
